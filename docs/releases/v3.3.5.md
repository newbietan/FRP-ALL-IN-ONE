# FRP-ALL-IN-ONE v3.3.5

本版本专注于 **Web 控制面板移动端排版与响应式布局的全面深度优化**。彻底解决了手机等移动端设备在访问控制台时出现的页面横向溢出、表格挤压变形、表单乱码以及全局弹窗错位等一系列显示与交互痛点，打造媲美原生体验的移动端管理后台。

---

## 核心改进与优化细节

### 1. 修复子隧道映射与数据表格的移动端撑破缺陷

- **问题原因**：
  - 展开客户端关联的“活跃穿透隧道映射列表”时，6 列子表格（包含上/下行实时流量）总宽度超过 650px，且外层包裹容器未配置横向滚动，导致展开瞬间强行将整个移动端视口横向撑大、页面产生大幅度左右晃动；
  - 仪表盘概览中的设备列表表格未做小屏滚动防护，字段挤压在一起难以阅读。
- **优化方案**：
  - 子表格外层全面升级为独立横向滚动容器（`overflow-x: auto`）并设置最小安全保护宽度（`min-w-[560px]`），在小屏下展开后即可平滑滑动查阅，杜绝撑破外层布局；
  - 概览列表增加 `overflow-x: auto` 与 `whitespace-nowrap` 保护，保证各列数据清晰可辨。

### 2. 重构新建映射弹窗（AddTunnelModal）表单布局

- **问题原因**：本地 IP、本地端口、远程映射端口三项输入原本采用硬性 3 列网格（`grid-cols-3`）。在手机 300px~360px 可用宽度下，单列宽度不足 90px，“填入 127.0.0.1 (本机)”等快捷标签与输入框互相剧烈挤压折行。
- **优化方案**：升级为响应式自适应网格（`grid-cols-1 sm:grid-cols-3`），在移动端自动垂直单列铺开，表单输入体验清晰整洁。

### 3. 主布局与移动端导航抽屉优化

- **防页面横向抖动**：根样式注入 `overflow-x: hidden; max-width: 100%` 并开启移动端平滑滚动（`-webkit-overflow-scrolling: touch`）；
- **工作区边距释放**：主内容区域边距从固定 `p-6`（手机端损失 48px）调整为 `p-3 sm:p-6`，大幅提升移动端有效显示区域；
- **侧边抽屉体验升级**：抽屉层级提升至 `z-50` 并在右上角新增直观的关闭按钮（`X`），支持点击遮罩或按钮快捷收起；
- **顶部状态栏紧凑化**：边距自适应，语言切换和退出按钮优化排版，防止小屏下与系统标题产生重叠折行。

### 4. 全局弹窗与操作按钮触控适配

- **实时日志监视窗（LogModal）**：外边距收窄为 `p-2 sm:p-4`，头部设备信息、清除、下载及关闭按钮在手机端优雅自动换行，底部日志统计垂直对齐；
- **版本升级与单机升级弹窗（UpdateModal）**：状态卡片、终端复制框、设备升级反馈在移动端自动垂直堆叠；
- **底部操作按钮适配**：所有弹窗的确认/取消/保存按钮在移动端采用全宽（`w-full sm:w-auto`）弹性排列，极大提升大拇指触控操作的舒适度与防误触能力。

## 升级与迁移

本项目从 v3.3.0 起已进入全新 443 原生 TLS 架构，**v3.3.0 及以上版本支持平滑无缝升级**：

### 服务端平滑升级

在服务端宿主机执行以下命令即可平滑升级至 v3.3.5：

```bash
curl -fsSL https://raw.githubusercontent.com/newbietan/FRP-ALL-IN-ONE/v3.3.5/deploy/upgrade.sh -o /tmp/frp-upgrade.sh
sudo bash /tmp/frp-upgrade.sh v3.3.5
```

### 客户端平滑升级

在 Web 控制台的「设备管理」列表中，直接点击可升级设备对应的「可升级」按钮并发送升级信号，升级成功后弹窗将自动更新版本并平滑关闭，无需手动刷新网页。
